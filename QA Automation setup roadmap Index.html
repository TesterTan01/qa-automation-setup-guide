    Turn this into portfolio projects

    1. Create one GitHub repo per tool, named by what it does, for example playwright-ts-saucedemo-tests.
    2. Test a public practice site, such as saucedemo.com or the Playwright demo todo app.
    3. Write a README with what you test, how to install, how to run, and a screenshot of the HTML report.
    4. Commit small and often. A history of steady commits shows how you work.
    5. Add a GitHub Actions workflow so a green tick appears on your repo.
